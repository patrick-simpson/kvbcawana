# Spare club art

Official Awana art supplied by the club, processed by
`scripts/prepare-club-gfx.py` (trimmed, downscaled, quantized) and
committed here for future slides/features. Vite only bundles assets
that `src/` code imports, so nothing in this folder adds to `dist/`
until it's actually used.

- `tnt/` — T&T "Agents of Grace" curriculum art: the four agent kids
  (Chase, Tommy, Nora, Marcos — two poses each), Rabbot the robot
  rabbit (also serves as the bundled `../tnt-mascot.png`), the group
  cover shot, the Agents of Grace title mark, and the blue T&T hexagon
  logo (doesn't read on the green banner wave, hence a spare).
- `puggles/` — Puggles clip art: the three toddler characters (Alice,
  Maya, Sydney), the Puggles duck (also serves as the bundled
  `../puggles-mascot.png`), the group shot, and the color/black
  Puggles wordmark logos.
