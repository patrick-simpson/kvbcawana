# kvbc-awana

KVBC's Awana screens in one repo, with the full history of the three repos it
replaces:

| Folder | Was | What it is |
| --- | --- | --- |
| `lobby/` | Awana-Check-in-Display | The lobby signage, the projector page, the sound room desktop app and the sync Worker |
| `journey/` | Journey-Display | The Journey kiosk |
| `printer/` | Print-TwoTimTwo-Labels | The Club Label Printer: the Windows app, the print server, the Chrome extension and its public site |

Moving to one site at awana.kvbchurch.org on Cloudflare is in progress; the
folders keep each app exactly as it was until then.
